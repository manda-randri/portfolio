Le client doit idéalement contrôler les ressources de production et payer les coûts récurrents du SaaS, tandis que toi tu factures ton développement et, éventuellement, ta maintenance.

function Show-ProjectTree {
    param($Path = "C:\Users\TOSHIBA\Desktop\Portfolio", $Depth = 3)
    
    function Show-Item($Item, $CurrentDepth, $Prefix = "") {
        if ($CurrentDepth -gt $Depth) { return }
        
        $name = $Item.Name
        if ($Item.PSIsContainer) {
            Write-Host "$Prefix📁 $name" -ForegroundColor Cyan
            Get-ChildItem $Item.FullName | ForEach-Object {
                Show-Item $_ ($CurrentDepth + 1) ($Prefix + "    ")
            }
        } else {
            Write-Host "$Prefix📄 $name" -ForegroundColor Gray
        }
    }
    
    Show-Item (Get-Item $Path) 0
}

Pour filtrer sur d'autres dossiers ou mots-clés, il suffit de remplacer 'project' par le nom de l'élément recherché entre guillemets simple.
Voici la commande de base et plusieurs exemples prêts à employer :
La formule générale
PowerShell
Get-ChildItem -Path "C:\Users\TOSHIBA\Desktop\Portfolio\portfolio\src" -Recurse | Where-Object { $_.FullName -match 'VOTRE_MOT_CLE' } | Select-Object FullName

Exemples d'utilisation selon vos besoins
1. Pour la section Hero (fond, animations, canvas) :
PowerShell
Get-ChildItem -Path "C:\Users\TOSHIBA\Desktop\Portfolio\portfolio\src" -Recurse | Where-Object { $_.FullName -match 'hero' } | Select-Object FullName

2. Pour les composants UI (boutons, sélecteur de langue, thème) :
PowerShell
Get-ChildItem -Path "C:\Users\TOSHIBA\Desktop\Portfolio\portfolio\src" -Recurse | Where-Object { $_.FullName -match 'components' } | Select-Object FullName

3. Pour la traduction et localisation (fichiers de langue) :
PowerShell
Get-ChildItem -Path "C:\Users\TOSHIBA\Desktop\Portfolio\portfolio\src" -Recurse | Where-Object { $_.FullName -match 'locales|i18n' } | Select-Object FullName

4. Pour chercher plusieurs mots à la fois (ex: hero OU project) :
Utilisez le symbole | entre les mots pour dire "ou".
PowerShell
Get-ChildItem -Path "C:\Users\TOSHIBA\Desktop\Portfolio\portfolio\src" -Recurse | Where-Object { $_.FullName -match 'hero|project' } | Select-Object FullName

5. Pour afficher uniquement les fichiers TypeScript (.tsx et .ts) :
PowerShell
Get-ChildItem -Path "C:\Users\TOSHIBA\Desktop\Portfolio\portfolio\src" -Recurse | Where-Object { $_.Extension -match '\.ts|\.tsx' } | Select-Object FullName
